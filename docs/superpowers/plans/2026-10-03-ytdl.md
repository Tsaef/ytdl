# ytdl — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Objectif :** une interface web personnelle pour yt-dlp, en ligne sur `yt.tsaef.fr` derrière un mot de passe : vidéo MP4, audio MP3, qualité au choix, playlists en ZIP ou en un seul fichier avec chapitres, fichiers servis avec reprise puis effacés.

**Architecture :** un seul conteneur Python (stdlib + yt-dlp comme bibliothèque, ffmpeg/ffprobe en sous-processus) avec une file de tâches en mémoire et 2 workers ; une page HTML/JS sans build ; Caddy gère le mot de passe et sert les fichiers terminés. Déploiement par la même CI/CD que les autres projets du VPS (validation manuelle, clé bridée par `deploy-gate.sh`).

**Stack :** Python 3.14 (stdlib : `http.server`, `threading`, `zipfile`, `unittest`), `yt-dlp[default]` (version figée), ffmpeg + ffprobe, deno, Alpine, Caddy, docker compose, GitHub Actions + Dependabot.

**Spec :** `docs/superpowers/specs/2026-10-03-ytdl-design.md` (commit `b3e6681`). Lire la spec avant chaque tâche : ce plan l'applique, il ne la remplace pas.

## Contraintes globales

- Python 3.14 ; **aucune dépendance pip hors `yt-dlp[default]`**, figé dans `requirements.txt`. Pas de framework web, pas de framework JS, pas d'étape de build.
- Interface, messages d'erreur et commentaires en **français** ; identifiants de code en anglais.
- `YTDL_WORKERS` = **2** ; marge disque `YTDL_DISK_FLOOR` = **10 Go** ; durée de vie `YTDL_TTL` = **6 h** ; **200** vidéos max par playlist ; nettoyage toutes les **5 min**.
- MP3 : **CBR 192 kb/s, 44,1 kHz, stéréo**. Vidéo : H.264 + AAC préférés (`bv*[height<=H][vcodec^=avc1]+ba[acodec^=mp4a]/bv*[height<=H]+ba/b[height<=H]`).
- Ré-encodage : `libx264 -preset veryfast -crf 23`, hauteur = min(plafond, plus grande hauteur, 1080), cadre 16:9 avec bandes noires, 30 i/s, AAC 160 kb/s 48 kHz stéréo, `-threads 2`.
- Extracteur générique **désactivé** (`allowed_extractors: ["default", "-generic"]`), `noplaylist: True`, URL `http(s)://` uniquement.
- Conteneur : uid **1000**, aucun port publié, `mem_limit: 768m`, `cpus: 2`, données dans `/data` (`~/stack/apps/ytdl-data`).
- **Les copies de `cookies.txt` ne vont jamais dans `/data/jobs`** : Caddy sert ce dossier.
- Tests : `unittest` de la stdlib, **aucun appel réseau** ; tests ffmpeg sautés si ffmpeg manque, sauf avec `YTDL_REQUIRE_FFMPEG=1`.
- Commits : messages en français au format `type: description`, avec la ligne `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Écarts assumés par rapport à la spec

Choix faits en écrivant le code ; à signaler en relecture s'ils ne conviennent pas.

1. **§8, place manquante pour un fichier unique** : au lieu d'échouer (et de perdre des heures de téléchargement), la tâche est livrée **en ZIP**, qui efface au fur et à mesure, avec une note « Pas assez d'espace disque pour un fichier unique : livré en ZIP. ». D'où un champ `note` en plus dans la tâche (§5).
2. **§12** : les tâches en erreur ou annulées expirent aussi après le TTL, pour que la liste en mémoire ne grossisse pas indéfiniment.
3. **§7** : les fichiers sont nommés par `formats.safe_name` (caractères interdits remplacés, 180 octets max) plutôt que par `windowsfilenames` de yt-dlp, puisque yt-dlp écrit sous des noms fixes (`001.mp4`) et que ytdl renomme lui-même.
4. **§7** : la conversion MP3 est faite par `assemble.to_mp3` (mêmes réglages), pas par un postprocesseur yt-dlp ; un postprocesseur `FFmpegVideoRemuxer` garantit le conteneur MP4 quand yt-dlp retombe sur un format non MP4.
5. **§9/§12** : unités des variables : `YTDL_DISK_FLOOR` en Go, `YTDL_TTL` en heures ; `YTDL_REENCODE_FACTOR` (défaut 1.0) rend le facteur d'estimation réglable.

## Points d'attention pour la relecture

Les cinq situations qu'un utilisateur rencontrera et que la spec n'énonce pas explicitement ; chacune a son test dans la tâche indiquée.

1. **Copie des cookies servie par Caddy** : une copie de `cookies.txt` posée dans `jobs/<id>/` serait téléchargeable via `/files/<id>/…`. Attendu : les copies vivent dans `/data/cookie-copies`, `jobs/<id>/` ne contient que le fichier livré. → Tâches 1 et 8.
2. **`jobs/` est un montage bind dans Caddy** : supprimer puis recréer le dossier au démarrage laisserait Caddy sur l'ancien inode, vide pour toujours. Attendu : `start()` vide le dossier sans le supprimer. → Tâche 8.
3. **`cookies.txt` renouvelé pendant une tâche** : la tâche ne doit pas écraser le nouveau fichier en recopiant sa vieille copie à la fin. → Tâche 4.
4. **Titres hostiles** : `/`, `:`, `?`, retours à la ligne, emoji, titres de 300 caractères. Attendu : un nom valide partout, jamais plus de 180 octets, jamais vide. → Tâche 2.
5. **Requêtes API mal formées** : JSON invalide, tableau au lieu d'objet, hauteur en chaîne ou booléen, `file://`, corps trop gros. Attendu : 400 avec un message, jamais de 500 ni de connexion coupée. → Tâche 9.

```python
"""Réglages lus dans l'environnement (spec §9, §12)."""
import os
from dataclasses import dataclass
from pathlib import Path

GB = 1024**3


@dataclass(frozen=True)
class Settings:
    data_dir: Path
    workers: int = 2
    disk_floor: int = 10 * GB
    ttl: float = 6 * 3600.0
    reencode_factor: float = 1.0
    port: int = 8000

    @property
    def jobs_dir(self) -> Path:
        return self.data_dir / "jobs"

    @property
    def cookie_copies_dir(self) -> Path:
        # Hors de jobs/ : Caddy sert jobs/, une copie des cookies ne doit jamais y passer.
        return self.data_dir / "cookie-copies"

    @property
    def cookies_file(self) -> Path:
        return self.data_dir / "cookies.txt"


def from_env(env=os.environ) -> Settings:
    return Settings(
        data_dir=Path(env.get("YTDL_DATA", "/data")),
        workers=int(env.get("YTDL_WORKERS", "2")),
        disk_floor=int(float(env.get("YTDL_DISK_FLOOR", "10")) * GB),
        ttl=float(env.get("YTDL_TTL", "6")) * 3600,
        reencode_factor=float(env.get("YTDL_REENCODE_FACTOR", "1.0")),
        port=int(env.get("YTDL_PORT", "8000")),
    )
```

```python
"""Erreurs de tâche et classement des messages yt-dlp / ffmpeg (spec §10)."""
from .config import GB

MESSAGES = {
    "cookies": "Cookies expirés : à renouveler",
    "unavailable": "Vidéo indisponible",
    "unsupported": "Lien non pris en charge",
    "disk": "Espace disque insuffisant",
    "network": "Erreur réseau, réessaie",
    "live": "Les directs ne sont pas pris en charge",
    "other": "Échec du téléchargement",
}

# L'ordre compte : « Private video. Sign in if you've been granted access… » doit
# rester une vidéo indisponible, pas un problème de cookies.
_PATTERNS = (
    ("unavailable", ("video unavailable", "private video", "in your country", "members-only", "has been removed")),
    ("cookies", ("sign in to confirm", "cookies are no longer valid")),
    ("unsupported", ("unsupported url", "no suitable extractor")),
    ("live", ("live event will begin", "premieres in")),
    ("network", ("timed out", "connection refused", "connection reset", "name resolution", "http error 5", "network is unreachable")),
)


class Cancelled(Exception):
    """Tâche annulée par l'utilisateur."""


class JobError(Exception):
    def __init__(self, kind: str, message: str | None = None, details: str = ""):
        self.kind = kind
        self.message = message or MESSAGES[kind]
        self.details = details
        super().__init__(self.message)

    def to_dict(self) -> dict:
        return {"kind": self.kind, "message": self.message, "details": self.details}


def last_line(text: str) -> str:
    lines = [line.strip() for line in text.strip().splitlines() if line.strip()]
    return lines[-1] if lines else ""


def classify(raw: str) -> JobError:
    low = raw.lower()
    kind = next((k for k, needles in _PATTERNS if any(n in low for n in needles)), "other")
    return JobError(kind, details=last_line(raw))


def disk_error(need_bytes: int = 0) -> JobError:
    if need_bytes:
        size = f"{need_bytes / GB:.1f}".replace(".", ",")
        return JobError("disk", f"Espace disque insuffisant ({size} Go nécessaires)")
    return JobError("disk")
```

```python
"""Options yt-dlp et lecture des infos qu'il renvoie (spec §6, §7). N'importe pas yt-dlp."""
import re
from pathlib import Path

MAX_ITEMS = 200
MP3_BITRATE = 192_000

_FORBIDDEN = re.compile(r'[\\/:*?"<>|\x00-\x1f]')


def base_options(cookiefile: Path | None) -> dict:
    options = {
        "quiet": True,
        "no_warnings": True,
        "noprogress": True,
        # watch?v=…&list=… donne la vidéo ; playlist?list=… donne la playlist.
        "noplaylist": True,
        # Une playlist est lue en surface (titres, liens) : chaque vidéo est extraite à part.
        "extract_flat": "in_playlist",
        "playlistend": MAX_ITEMS,
        # Sans l'extracteur générique, yt-dlp refuse les URL arbitraires (spec §13).
        "allowed_extractors": ["default", "-generic"],
    }
    if cookiefile is not None:
        options["cookiefile"] = str(cookiefile)
    return options


def video_selector(height: int | None) -> str:
    cap = f"[height<={height}]" if height else ""
    return f"bv*{cap}[vcodec^=avc1]+ba[acodec^=mp4a]/bv*{cap}+ba/b{cap}"


def format_options(fmt: str, height: int | None) -> dict:
    if fmt == "mp4":
        return {
            "format": video_selector(height),
            "merge_output_format": "mp4",
            # Sans effet sur un MP4 ; garantit le conteneur si yt-dlp retombe sur « b ».
            "postprocessors": [{"key": "FFmpegVideoRemuxer", "preferedformat": "mp4"}],
        }
    if fmt == "mp3":
        # Piste audio brute : assemble.to_mp3 convertit avec des réglages identiques
        # pour toutes les pistes, ce qui permet l'assemblage par copie.
        return {"format": "ba/b"}
    raise ValueError(f"format inconnu : {fmt}")


def _size(fmt: dict) -> int | None:
    return fmt.get("filesize") or fmt.get("filesize_approx")


def estimate_size(info: dict) -> int | None:
    """Taille du format retenu par yt-dlp ; None si une partie est inconnue."""
    parts = info.get("requested_formats")
    if parts:
        sizes = [_size(p) for p in parts]
        return sum(sizes) if all(sizes) else None
    return _size(info)


def is_live(info: dict) -> bool:
    return bool(info.get("is_live")) or info.get("live_status") in ("is_live", "is_upcoming")


def is_playlist(info: dict) -> bool:
    return info.get("_type") == "playlist"


def playlist_entries(info: dict) -> list[dict]:
    entries = []
    for entry in info.get("entries") or []:
        if not entry:
            continue
        url = entry.get("url") or entry.get("webpage_url")
        if url:
            entries.append({"url": url, "title": entry.get("title") or url, "duration": entry.get("duration")})
    return entries[:MAX_ITEMS]


def _is_video(fmt: dict) -> bool:
    return fmt.get("vcodec") not in (None, "none") and bool(fmt.get("height"))


def best_audio(formats: list[dict]) -> dict | None:
    audios = [f for f in formats if f.get("vcodec") == "none" and f.get("acodec") not in (None, "none")]
    if not audios:
        return None
    return max(audios, key=lambda f: (str(f.get("acodec", "")).startswith("mp4a"), f.get("abr") or 0))


def height_options(formats: list[dict]) -> list[dict]:
    """Hauteurs disponibles, de la plus haute à la plus basse, avec leur taille estimée."""
    videos = [f for f in formats if _is_video(f)]
    audio = best_audio(formats)
    options = []
    for height in sorted({f["height"] for f in videos}, reverse=True):
        at_height = [f for f in videos if f["height"] == height]
        h264 = [f for f in at_height if str(f.get("vcodec", "")).startswith("avc1")]
        pick = max(h264 or at_height, key=lambda f: f.get("tbr") or 0)
        size = _size(pick)
        if size and pick.get("acodec") in (None, "none") and audio:
            audio_size = _size(audio)
            size = size + audio_size if audio_size else None
        options.append({"height": height, "size": size})
    return options


def mp3_size(duration: float | None) -> int | None:
    return int(duration * MP3_BITRATE / 8) if duration else None


def summarize(info: dict) -> dict:
    """Réponse de /api/analyze (spec §6)."""
    if is_playlist(info):
        entries = playlist_entries(info)
        return {
            "kind": "playlist",
            "title": info.get("title") or "Playlist",
            "count": len(entries),
            "entries": [{"title": e["title"], "duration": e["duration"]} for e in entries],
        }
    return {
        "kind": "video",
        "title": info.get("title") or "Vidéo",
        "duration": info.get("duration"),
        "thumbnail": info.get("thumbnail"),
        "heights": height_options(info.get("formats") or []),
        "mp3_size": mp3_size(info.get("duration")),
    }


def safe_name(title: str | None, limit: int = 180) -> str:
    """Nom de fichier valide partout (Windows compris), limité en octets (ext4 : 255)."""
    name = re.sub(r"\s+", " ", _FORBIDDEN.sub("_", title or "")).strip().strip(".")
    while len(name.encode()) > limit:
        name = name[:-1]
    return name.rstrip(" .") or "sans titre"


def numbered(index: int, count: int, title: str, ext: str) -> str:
    width = max(2, len(str(count)))
    return f"{index:0{width}d} - {safe_name(title)}.{ext}"
```

```python
"""Marge d'espace disque toujours laissée au reste du VPS (spec §9)."""
import shutil
import threading
import time
from pathlib import Path

from .errors import disk_error


class DiskGuard:
    def __init__(self, path: Path, floor: int, usage=shutil.disk_usage, clock=time.monotonic):
        self._path = path
        self._floor = floor
        self._usage = usage
        self._clock = clock
        self._lock = threading.Lock()
        self._reserved: dict[str, int] = {}
        self._last_check = float("-inf")

    def free(self) -> int:
        return self._usage(self._path).free

    def reserve(self, key: str, need: int) -> None:
        """Réserve need octets pour key (remplace sa réservation) ou lève JobError('disk')."""
        with self._lock:
            others = sum(v for k, v in self._reserved.items() if k != key)
            if self.free() - others - need < self._floor:
                raise disk_error(need)
            self._reserved[key] = need

    def release(self, key: str) -> None:
        with self._lock:
            self._reserved.pop(key, None)

    def check(self) -> None:
        """Surveillance pendant un téléchargement : au plus une mesure par seconde."""
        now = self._clock()
        if now - self._last_check < 1:
            return
        self._last_check = now
        if self.free() < self._floor:
            raise disk_error()
```

```python
"""cookies.txt partagé entre les tâches (spec §11).

Chaque tâche travaille sur sa propre copie ; yt-dlp la met à jour (la session se
prolonge) et elle est recopiée à la fin, sauf si l'utilisateur a déposé un nouveau
fichier entre-temps : celui-ci gagne toujours.
"""
import os
import shutil
import threading
from pathlib import Path


class CookieStore:
    def __init__(self, path: Path):
        self.path = path
        self._lock = threading.Lock()
        self._state = "unknown"
        self._state_version = None  # version du fichier au moment du dernier verdict

    def _version(self):
        try:
            st = self.path.stat()
        except FileNotFoundError:
            return None
        return (st.st_mtime_ns, st.st_size)

    @property
    def state(self) -> str:
        with self._lock:
            version = self._version()
            if version is None:
                return "absent"
            if version != self._state_version:
                return "unknown"  # fichier remplacé depuis le dernier verdict
            return self._state

    def mark(self, state: str) -> None:
        """'ok' après un succès YouTube, 'expired' après une erreur de cookies."""
        with self._lock:
            self._state = state
            self._state_version = self._version()

    def checkout(self, dest: Path):
        """Copie cookies.txt vers dest ; renvoie sa version, ou None s'il est absent."""
        with self._lock:
            version = self._version()
            if version is None:
                return None
            dest.parent.mkdir(parents=True, exist_ok=True)
            shutil.copyfile(self.path, dest)
            os.chmod(dest, 0o600)
            return version

    def checkin(self, copy: Path, version) -> None:
        """Recopie la copie d'une tâche si l'original n'a pas changé ; efface la copie."""
        with self._lock:
            try:
                if version is not None and copy.exists() and self._version() == version:
                    tmp = self.path.with_name(self.path.name + ".tmp")
                    shutil.copyfile(copy, tmp)
                    os.chmod(tmp, 0o600)
                    os.replace(tmp, self.path)
                    if self._state_version == version:
                        self._state_version = self._version()
            finally:
                copy.unlink(missing_ok=True)
```

```python
"""Assemblages (spec §8) : ZIP, chapitres, et ffmpeg / ffprobe en sous-processus."""
import re
import threading
import zipfile
from dataclasses import dataclass
from pathlib import Path

from .errors import Cancelled


@dataclass(frozen=True)
class Media:
    duration: float
    video: tuple | None  # (codec, largeur, hauteur, images/s) ; None pour un fichier audio
    audio: tuple | None  # (codec, fréquence, canaux) ; None sans piste audio

    @property
    def height(self) -> int | None:
        return self.video[2] if self.video else None


def compatible(medias: list[Media]) -> bool:
    """Assemblage par copie possible : mêmes paramètres vidéo et audio partout."""
    first = medias[0]
    return all(m.video == first.video and m.audio == first.audio for m in medias)


def target_height(medias: list[Media], cap: int | None) -> int:
    """Hauteur du ré-encodage : min(plafond choisi, plus grande hauteur, 1080)."""
    tallest = max((m.height or 0) for m in medias) or 1080
    return min(cap or 1080, tallest, 1080)


def frame_width(height: int) -> int:
    """Largeur paire d'un cadre 16:9 (libx264 exige des dimensions paires)."""
    return (height * 16 // 9 + 1) // 2 * 2


def reencode_estimate(medias: list[Media], height: int, factor: float) -> int:
    """Secondes de calcul : durée totale × facteur (donné pour 1080p), au prorata des pixels."""
    total = sum(m.duration for m in medias)
    return round(total * factor * (height / 1080) ** 2)


def _escape(text: str) -> str:
    return re.sub(r"([=;#\\\n])", r"\\\1", text)


def ffmetadata(titles: list[str], durations: list[float]) -> str:
    """Fichier de chapitres ffmpeg : un chapitre par morceau, bout à bout."""
    lines = [";FFMETADATA1"]
    end = 0.0
    for title, duration in zip(titles, durations):
        start, end = end, end + duration
        lines += ["[CHAPTER]", "TIMEBASE=1/1000", f"START={round(start * 1000)}",
                  f"END={round(end * 1000)}", f"title={_escape(title)}"]
    return "\n".join(lines) + "\n"


def zip_files(entries: list[tuple[Path, str]], out: Path, cancel: threading.Event | None = None) -> None:
    """ZIP sans compression (médias déjà compressés) ; chaque fichier est effacé une fois archivé."""
    with zipfile.ZipFile(out, "w", compression=zipfile.ZIP_STORED, allowZip64=True) as archive:
        for path, arcname in entries:
            if cancel is not None and cancel.is_set():
                raise Cancelled()
            archive.write(path, arcname)
            path.unlink()
```

```python
FFMPEG = ["ffmpeg", "-hide_banner", "-loglevel", "error", "-nostdin", "-y"]
THREADS = ["-threads", "2"]  # avec cpus: 2 dans compose, laisse des cœurs à Minecraft


def run(args: list[str], cancel: threading.Event | None = None) -> None:
    """Lance ffmpeg ; Cancelled si cancel est levé pendant l'exécution, JobError s'il échoue."""
    with tempfile.TemporaryFile() as stderr:
        proc = subprocess.Popen(FFMPEG + args, stdin=subprocess.DEVNULL, stdout=subprocess.DEVNULL, stderr=stderr)
        while True:
            try:
                code = proc.wait(timeout=0.5)
                break
            except subprocess.TimeoutExpired:
                if cancel is not None and cancel.is_set():
                    proc.kill()
                    proc.wait()
                    raise Cancelled() from None
        if code != 0:
            stderr.seek(0)
            raise JobError("other", "Échec de la conversion", last_line(stderr.read().decode(errors="replace")))


def probe(path: Path) -> Media:
    proc = subprocess.run(
        ["ffprobe", "-v", "error", "-show_entries",
         "format=duration:stream=codec_type,codec_name,width,height,r_frame_rate,sample_rate,channels",
         "-of", "json", str(path)],
        capture_output=True, text=True,
    )
    if proc.returncode != 0:
        raise JobError("other", "Échec de la conversion", last_line(proc.stderr))
    data = json.loads(proc.stdout)
    streams = data.get("streams", [])
    v = next((s for s in streams if s.get("codec_type") == "video"), None)
    a = next((s for s in streams if s.get("codec_type") == "audio"), None)
    return Media(
        duration=float(data["format"]["duration"]),
        video=(v["codec_name"], v["width"], v["height"], v["r_frame_rate"]) if v else None,
        audio=(a["codec_name"], a["sample_rate"], a["channels"]) if a else None,
    )


def to_mp3(src: Path, out: Path, cancel: threading.Event | None = None) -> None:
    """MP3 CBR 192 kb/s, 44,1 kHz, stéréo : identique pour toutes les pistes (spec §7)."""
    run(["-i", str(src), "-vn", "-c:a", "libmp3lame", "-b:a", "192k", "-ar", "44100", "-ac", "2",
         *THREADS, str(out)], cancel)


def _concat_list(files: list[Path], path: Path) -> None:
    # Démultiplexeur concat : chemins absolus entre apostrophes, une apostrophe s'écrit '\''.
    path.write_text("".join("file '" + str(f.resolve()).replace("'", "'\\''") + "'\n" for f in files))


def concat_copy(files: list[Path], titles: list[str], durations: list[float], out: Path,
                cancel: threading.Event | None = None) -> None:
    """Met les fichiers bout à bout sans ré-encoder, avec un chapitre par fichier."""
    listing = out.with_name(out.name + ".concat.txt")
    chapters = out.with_name(out.name + ".chapters.txt")
    _concat_list(files, listing)
    chapters.write_text(ffmetadata(titles, durations))
    try:
        run(["-f", "concat", "-safe", "0", "-i", str(listing), "-i", str(chapters),
             "-map", "0", "-map_metadata", "1", "-map_chapters", "1", "-c", "copy", str(out)], cancel)
    finally:
        listing.unlink(missing_ok=True)
        chapters.unlink(missing_ok=True)


def normalize(src: Path, media: Media, height: int, out: Path, cancel: threading.Event | None = None) -> None:
    """Ré-encode vers le format commun (spec §8) : H.264 + AAC, cadre 16:9, 30 i/s."""
    width = frame_width(height)
    video_filter = (f"scale={width}:{height}:force_original_aspect_ratio=decrease:force_divisible_by=2,"
                    f"pad={width}:{height}:(ow-iw)/2:(oh-ih)/2,setsar=1,fps=30,format=yuv420p")
    args = ["-i", str(src)]
    if media.audio is None:
        # Sans piste audio, l'assemblage par copie échouerait : on ajoute un silence.
        args += ["-f", "lavfi", "-i", "anullsrc=r=48000:cl=stereo", "-map", "0:v:0", "-map", "1:a:0", "-shortest"]
    else:
        args += ["-map", "0:v:0", "-map", "0:a:0"]
    args += ["-vf", video_filter, "-c:v", "libx264", "-preset", "veryfast", "-crf", "23",
             "-c:a", "aac", "-b:a", "160k", "-ar", "48000", "-ac", "2", *THREADS, str(out)]
    run(args, cancel)
```

```python
from pathlib import Path


class FakeYDL:
    """Imite la partie de yt_dlp.YoutubeDL utilisée par Downloader."""

    infos: dict = {}       # url -> dict d'infos, ou exception à lever
    progress: list = []    # dicts passés aux progress_hooks pendant le téléchargement
    instances: list = []
    processed = 0

    def __init__(self, opts):
        self.opts = opts
        FakeYDL.instances.append(self)

    @classmethod
    def reset(cls):
        cls.infos, cls.progress, cls.instances, cls.processed = {}, [], [], 0

    def __enter__(self):
        return self

    def __exit__(self, *exc):
        return False

    def extract_info(self, url, download=False):
        assert download is False
        result = FakeYDL.infos[url]
        if isinstance(result, Exception):
            raise result
        return dict(result)

    def process_ie_result(self, info, download=True):
        FakeYDL.processed += 1
        try:
            for d in FakeYDL.progress:
                for hook in self.opts.get("progress_hooks", []):
                    hook(d)
        except Exception as e:
            # yt-dlp emballe les exceptions des hooks dans une DownloadError.
            raise RuntimeError(f"ERROR: interrupted: {e!r}") from e
        path = Path(self.opts["outtmpl"].replace("%(ext)s", "mp4"))
        path.write_bytes(b"video")
        return {**info, "requested_downloads": [{"filepath": str(path)}]}
```

```python
class Item:

    title: str
    duration: float | None


@dataclass
class Playlist:

class Downloader:
    def __init__(self, guard: DiskGuard, ydl_class=None):
        self._guard = guard
        self._ydl_class = ydl_class

    def _ydl(self, cookiefile: Path | None, extra: dict | None = None):
        return (self._ydl_class or _yt_dlp_class())(formats.base_options(cookiefile) | (extra or {}))

    def _extract(self, url: str, cookiefile: Path | None, extra: dict | None = None) -> dict:
        try:
            with self._ydl(cookiefile, extra) as ydl:
                info = ydl.extract_info(url, download=False)
        except Exception as e:
            raise classify(str(e)) from e
        if formats.is_live(info):
            raise JobError("live")
        return info

    def analyze(self, url: str, cookiefile: Path | None) -> dict:
        return formats.summarize(self._extract(url, cookiefile))

    def resolve(self, url: str, fmt: str, height: int | None, cookiefile: Path | None) -> Playlist | dict:
        info = self._extract(url, cookiefile, formats.format_options(fmt, height))
        if formats.is_playlist(info):
            return Playlist(info.get("title") or "Playlist", formats.playlist_entries(info))
        return info

    def fetch(self, target, fmt: str, height: int | None, dest_stem: Path, cookiefile: Path | None,
              key: str, on_progress, cancel: threading.Event) -> Item:
        """Télécharge une vidéo seule (URL, ou infos venant de resolve) vers dest_stem.<ext>."""
        if isinstance(target, dict):
            info = target
        else:
            info = self._extract(target, cookiefile, formats.format_options(fmt, height))
        estimate = formats.estimate_size(info)
        self._guard.reserve(key, 2 * estimate if estimate else 0)
        aborted: list[Exception] = []
        finished: dict = {}  # octets des parties terminées (vidéo, puis audio)

        def hook(d: dict) -> None:
            try:
                if cancel.is_set():
                    raise Cancelled()
                self._guard.check()
            except (Cancelled, JobError) as e:
                aborted.append(e)  # yt-dlp emballe l'exception : on garde l'originale
                raise
            if d.get("status") == "finished":
                finished[d.get("filename")] = d.get("total_bytes") or d.get("downloaded_bytes") or 0
            elif d.get("status") == "downloading":
                if estimate:
                    done, total = sum(finished.values()) + (d.get("downloaded_bytes") or 0), estimate
                else:
                    done, total = d.get("downloaded_bytes") or 0, d.get("total_bytes") or d.get("total_bytes_estimate")
                on_progress(min(100.0, 100.0 * done / total) if total else None, d.get("speed"), d.get("eta"))

        options = formats.format_options(fmt, height) | {
            "outtmpl": str(dest_stem) + ".%(ext)s",
            "progress_hooks": [hook],
        }
        dest_stem.parent.mkdir(parents=True, exist_ok=True)
        try:
            with self._ydl(cookiefile, options) as ydl:
                result = ydl.process_ie_result(info, download=True)
        except Exception as e:
            if aborted:
                raise aborted[0] from e
            raise classify(str(e)) from e
        finally:
            self._guard.release(key)
        return Item(_output(result, dest_stem), info.get("title") or dest_stem.name, info.get("duration"))


def _output(result: dict, dest_stem: Path) -> Path:
    """Fichier final : celui que yt-dlp déclare, sinon le plus gros dest_stem.*."""
    for download in result.get("requested_downloads") or []:
        path = download.get("filepath")
        if path and Path(path).exists():
            return Path(path)
    found = [p for p in dest_stem.parent.glob(dest_stem.name + ".*") if p.suffix not in (".part", ".ytdl")]
    if not found:
        raise JobError("other", details="fichier téléchargé introuvable")
    return max(found, key=lambda p: p.stat().st_size)
```

```python
    decision: dict | None = None
    file: dict | None = None
    skipped: list = field(default_factory=list)
    note: str | None = None
    finished_at: float | None = None
    expires_at: float | None = None
    cancel: threading.Event = field(default_factory=threading.Event)
    pending: list = field(default_factory=list)  # [(Item, Media)] en attente de décision

    def to_dict(self) -> dict:
        return {key: copy.deepcopy(getattr(self, key)) for key in PUBLIC}


def _empty(directory: Path) -> None:
    """Vide un dossier sans le supprimer : jobs/ est monté tel quel dans Caddy."""
    directory.mkdir(parents=True, exist_ok=True)
    for child in directory.iterdir():
        if child.is_dir() and not child.is_symlink():
            shutil.rmtree(child, ignore_errors=True)
        else:
            child.unlink(missing_ok=True)


class JobManager:
    def __init__(self, settings, downloader, cookies, guard, assembler=assemble, clock=time.time):
        self.settings = settings
        self._dl = downloader
        self._cookies = cookies
        self._guard = guard
        self._asm = assembler
        self._clock = clock
        self._lock = threading.RLock()
        self._jobs: dict[str, Job] = {}
        self._queue: queue.Queue = queue.Queue()

    # ---- cycle de vie ---------------------------------------------------
    def start(self) -> None:
        # Les tâches en mémoire sont perdues au redémarrage : leurs fichiers aussi.
        _empty(self.settings.jobs_dir)
        _empty(self.settings.cookie_copies_dir)
        for _ in range(self.settings.workers):
            threading.Thread(target=self._worker, daemon=True).start()
        threading.Thread(target=self._janitor, daemon=True).start()

    def _janitor(self) -> None:
        while True:
            time.sleep(300)
            self.sweep()

    def sweep(self) -> None:
        now = self._clock()
        with self._lock:
            expired = [j for j in self._jobs.values() if j.expires_at is not None and j.expires_at <= now]
            for job in expired:
                del self._jobs[job.id]
        for job in expired:
            shutil.rmtree(self._dir(job), ignore_errors=True)

    # ---- API ------------------------------------------------------------
    def analyze(self, url: str) -> dict:
        copy_path = self.settings.cookie_copies_dir / f"analyze-{uuid.uuid4().hex}.txt"
        version = self._cookies.checkout(copy_path)
        try:
            return self._dl.analyze(url, copy_path if version else None)
        except JobError as e:
            if e.kind == "cookies":
                self._cookies.mark("expired")
            raise
        finally:
            self._cookies.checkin(copy_path, version)

    def submit(self, url: str, fmt: str, height: int | None, playlist_mode: str | None) -> dict:
        job = Job(uuid.uuid4().hex, url, fmt, height, playlist_mode, created_at=self._clock())
        with self._lock:
            self._jobs[job.id] = job
        self._queue.put((job, "run"))
        return self.get(job.id)

    def get(self, job_id: str) -> dict | None:
        with self._lock:
            job = self._jobs.get(job_id)
            return job.to_dict() if job else None

    def list_jobs(self) -> list[dict]:
        with self._lock:
            jobs = sorted(self._jobs.values(), key=lambda j: j.created_at, reverse=True)
            return [j.to_dict() for j in jobs]

    def delete(self, job_id: str) -> bool:
        """Annule une tâche en attente ou en cours ; efface une tâche terminée."""
        with self._lock:
            job = self._jobs.get(job_id)
            if job is None:
                return False
            if job.state in ACTIVE:
                job.cancel.set()
                if job.state != "queued":
                    return True  # le worker voit l'annulation, efface et passe en « cancelled »
                self._finish(job, "cancelled")
            else:
                del self._jobs[job_id]
        shutil.rmtree(self._dir(job), ignore_errors=True)
        return True

    def decide(self, job_id: str, choice: str) -> dict | None:
        with self._lock:
            job = self._jobs.get(job_id)
            if job is None:
                return None
            if job.state != "awaiting_decision":
                raise Conflict("Aucune décision en attente pour cette tâche")
            job.state, job.decision, job.finished_at, job.expires_at = "queued", None, None, None
        self._queue.put((job, choice))
        return self.get(job_id)

    # ---- exécution ------------------------------------------------------
    def _dir(self, job: Job) -> Path:
        return self.settings.jobs_dir / job.id

    def _update(self, job: Job, **fields) -> None:
        with self._lock:
            for key, value in fields.items():
                setattr(job, key, value)

    def _finish(self, job: Job, state: str, **fields) -> None:
        now = self._clock()
        self._update(job, state=state, finished_at=now, expires_at=now + self.settings.ttl, progress={}, **fields)

    def _worker(self) -> None:
        while True:
            job, action = self._queue.get()
            self._execute(job, action)

    def _execute(self, job: Job, action: str) -> None:
        with self._lock:
            if job.cancel.is_set() or self._jobs.get(job.id) is not job:
                return
            job.state = "downloading" if action == "run" else "processing"
        # Copie des cookies HORS de jobs/ : Caddy sert jobs/.
        copy_path = self.settings.cookie_copies_dir / f"{job.id}.txt"
        version = self._cookies.checkout(copy_path) if action == "run" else None
        try:
            if action == "run":
                self._run(job, copy_path if version else None)
                if is_youtube(job.url):
                    self._cookies.mark("ok")
            elif action == "reencode":
                self._reencode(job)
            else:
                self._deliver_zip(job, [item for item, _ in job.pending])
        except Cancelled:
            shutil.rmtree(self._dir(job), ignore_errors=True)
            self._finish(job, "cancelled", pending=[])
        except JobError as e:
            if e.kind == "cookies":
                self._cookies.mark("expired")
            shutil.rmtree(self._dir(job), ignore_errors=True)
            self._finish(job, "error", error=e.to_dict(), pending=[])
        except Exception as e:  # filet : une tâche ne doit jamais tuer son worker
            shutil.rmtree(self._dir(job), ignore_errors=True)
            self._finish(job, "error", error=JobError("other", details=repr(e)).to_dict(), pending=[])
        finally:
            self._cookies.checkin(copy_path, version)
            self._guard.release(job.id)

    def _progress(self, job: Job, item: int | None = None, items: int | None = None):
        def report(percent, speed, eta):
            self._update(job, progress={"percent": percent, "speed_bps": speed, "eta_s": eta,
                                        "item": item, "items": items})
        return report

    def _run(self, job: Job, cookiefile: Path | None) -> None:
        dl_dir = self._dir(job) / "dl"
        target = self._dl.resolve(job.url, job.format, job.height, cookiefile)
        if isinstance(target, Playlist):
            self._update(job, title=target.title)
            items = self._fetch_playlist(job, target, dl_dir, cookiefile)
        else:
            self._update(job, title=target.get("title"))
            items = [self._dl.fetch(target, job.format, job.height, dl_dir / "001", cookiefile,
                                    job.id, self._progress(job), job.cancel)]
        self._update(job, state="processing", progress={})
        if job.format == "mp3":
            items = [self._to_mp3(job, item) for item in items]
        if not isinstance(target, Playlist):
            return self._ready(job, self._move_single(job, items[0]))
        if (job.playlist_mode or "zip") == "zip":
            return self._deliver_zip(job, items)
        medias = [self._asm.probe(item.path) for item in items]
        if job.format == "mp3" or self._asm.compatible(medias):
            return self._deliver_concat(job, items, medias)
        height = self._asm.target_height(medias, job.height)
        estimate = self._asm.reencode_estimate(medias, height, self.settings.reencode_factor)
        now = self._clock()
        self._update(job, state="awaiting_decision", pending=list(zip(items, medias)),
                     decision={"reencode_estimate_s": estimate}, finished_at=now,
                     expires_at=now + self.settings.ttl, progress={})

    def _fetch_playlist(self, job: Job, playlist: Playlist, dl_dir: Path, cookiefile: Path | None) -> list[Item]:
        items, skipped = [], []
        count = len(playlist.entries)
        for index, entry in enumerate(playlist.entries, 1):
            if job.cancel.is_set():
                raise Cancelled()
            self._update(job, progress={"percent": 0.0, "item": index, "items": count})
            try:
                items.append(self._dl.fetch(entry["url"], job.format, job.height, dl_dir / f"{index:03d}",
                                            cookiefile, job.id, self._progress(job, index, count), job.cancel))
            except JobError as e:
                if e.kind not in ("unavailable", "live"):
                    raise
                skipped.append(entry["title"])
                self._update(job, skipped=list(skipped))
        if not items:
            raise JobError("unavailable", "Aucune vidéo de la playlist n'est disponible")
        return items

    def _to_mp3(self, job: Job, item: Item) -> Item:
        out = item.path.with_name(item.path.stem + ".conv.mp3")
        self._asm.to_mp3(item.path, out, job.cancel)
        item.path.unlink()
        return Item(out, item.title, item.duration)

    def _move_single(self, job: Job, item: Item) -> Path:
        out = self._dir(job) / f"{formats.safe_name(item.title)}.{job.format}"
        item.path.replace(out)
        return out

    def _deliver_zip(self, job: Job, items: list[Item], note: str | None = None) -> None:
        out = self._dir(job) / f"{formats.safe_name(job.title)}.zip"
        entries = [(item.path, formats.numbered(i, len(items), item.title, job.format))
                   for i, item in enumerate(items, 1)]
        self._asm.zip_files(entries, out, job.cancel)
        self._ready(job, out, note)

    def _deliver_concat(self, job: Job, items: list[Item], medias: list) -> None:
        try:
            self._guard.reserve(job.id, sum(item.path.stat().st_size for item in items))
        except JobError:
            # Pas la place pour un fichier unique en plus des morceaux : le ZIP efface
            # chaque morceau dès qu'il est archivé, il tient toujours.
            return self._deliver_zip(job, items, NO_SPACE_NOTE)
        out = self._dir(job) / f"{formats.safe_name(job.title)}.{job.format}"
        self._asm.concat_copy([i.path for i in items], [i.title for i in items],
                              [m.duration for m in medias], out, job.cancel)
        for item in items:
            item.path.unlink()
        self._ready(job, out)

    def _reencode(self, job: Job) -> None:
        pending = job.pending
        height = self._asm.target_height([media for _, media in pending], job.height)
        items, medias = [], []
        for index, (item, media) in enumerate(pending, 1):
            if job.cancel.is_set():
                raise Cancelled()
            self._update(job, progress={"percent": None, "item": index, "items": len(pending)})
            out = item.path.with_name(item.path.stem + ".norm.mp4")
            self._asm.normalize(item.path, media, height, out, job.cancel)
            item.path.unlink()
            items.append(Item(out, item.title, item.duration))
            medias.append(self._asm.probe(out))
        self._update(job, progress={})
        self._deliver_concat(job, items, medias)

    def _ready(self, job: Job, out: Path, note: str | None = None) -> None:
        shutil.rmtree(self._dir(job) / "dl", ignore_errors=True)
        file = {"name": out.name, "size": out.stat().st_size, "url": f"/files/{job.id}/{quote(out.name)}"}
        self._finish(job, "ready", file=file, note=note, pending=[])
```

```python
"""Serveur HTTP : la page et l'API JSON (spec §5). Lancement : python -m ytdl.server"""
import json
import re
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from pathlib import Path
from urllib.parse import urlparse

from .config import from_env
from .cookies import CookieStore
from .disk import DiskGuard
from .downloader import Downloader
from .errors import JobError
from .jobs import Conflict, JobManager

WEB = Path(__file__).resolve().parent.parent / "web"
STATIC = {
    "/": ("index.html", "text/html; charset=utf-8"),
    "/app.js": ("app.js", "text/javascript; charset=utf-8"),
    "/style.css": ("style.css", "text/css; charset=utf-8"),
}
MAX_BODY = 64 * 1024
JOB_PATH = re.compile(r"^/api/jobs/([0-9a-f]{32})(/decision)?$")


class BadRequest(Exception):
    pass


def read_json(rfile, length_header: str | None) -> dict:
    try:
        length = int(length_header or 0)
    except ValueError:
        raise BadRequest("Content-Length invalide") from None
    if not 0 <= length <= MAX_BODY:
        raise BadRequest("Requête trop volumineuse")
    try:
        data = json.loads(rfile.read(length) or b"{}")
    except ValueError:  # comprend UnicodeDecodeError
        raise BadRequest("JSON invalide") from None
    if not isinstance(data, dict):
        raise BadRequest("Objet JSON attendu")
    return data


def parse_url(value) -> str:
    if not isinstance(value, str) or len(value) > 2000:
        raise BadRequest("Lien invalide")
    value = value.strip()
    parsed = urlparse(value)
    if parsed.scheme not in ("http", "https") or not parsed.netloc:
        raise BadRequest("Lien invalide : http(s) attendu")
    return value


def parse_job_request(body: dict) -> tuple:
    url = parse_url(body.get("url"))
    fmt = body.get("format")
    if fmt not in ("mp4", "mp3"):
        raise BadRequest("Format invalide : mp4 ou mp3")
    height = body.get("height")
    if height is not None and (type(height) is not int or not 144 <= height <= 4320):
        raise BadRequest("Qualité invalide")
    mode = body.get("playlist_mode")
    if mode not in (None, "zip", "concat"):
        raise BadRequest("Mode de playlist invalide : zip ou concat")
    return url, fmt, height, mode


def make_handler(manager: JobManager, cookies: CookieStore, guard: DiskGuard):
    class Handler(BaseHTTPRequestHandler):
        server_version = "ytdl"

        def log_message(self, format, *args):  # Caddy journalise déjà chaque requête
            pass

        def _send(self, status, payload=None, body=None, content_type="application/json; charset=utf-8"):
            data = body if body is not None else json.dumps(payload, ensure_ascii=False).encode()
            self.send_response(status)
            self.send_header("Content-Type", content_type)
            self.send_header("Content-Length", str(len(data)))
            self.send_header("Cache-Control", "no-store")
            self.end_headers()
            self.wfile.write(data)

        def _error(self, status, kind, message, details=""):
            self._send(status, {"error": {"kind": kind, "message": message, "details": details}})

        def do_GET(self):
            path = urlparse(self.path).path
            if path in STATIC:
                name, content_type = STATIC[path]
                return self._send(200, body=(WEB / name).read_bytes(), content_type=content_type)
            if path == "/api/status":
                return self._send(200, {"cookies": cookies.state, "disk_free_bytes": guard.free()})
            if path == "/api/jobs":
                return self._send(200, manager.list_jobs())
            match = JOB_PATH.match(path)
            job = manager.get(match.group(1)) if match and not match.group(2) else None
            if job is None:
                return self._error(404, "not_found", "Introuvable")
            self._send(200, job)

        def do_POST(self):
            path = urlparse(self.path).path
            match = JOB_PATH.match(path)
            try:
                body = read_json(self.rfile, self.headers.get("Content-Length"))
                if path == "/api/analyze":
                    return self._send(200, manager.analyze(parse_url(body.get("url"))))
                if path == "/api/jobs":
                    return self._send(201, manager.submit(*parse_job_request(body)))
                if match and match.group(2):
                    if body.get("choice") not in ("reencode", "zip"):
                        raise BadRequest("Choix invalide : reencode ou zip")
                    job = manager.decide(match.group(1), body["choice"])
                    if job is None:
                        return self._error(404, "not_found", "Tâche introuvable")
                    return self._send(200, job)
                self._error(404, "not_found", "Introuvable")
            except BadRequest as e:
                self._error(400, "bad_request", str(e))
            except Conflict as e:
                self._error(409, "conflict", str(e))
            except JobError as e:
                self._send(422, {"error": e.to_dict()})
            except Exception as e:  # jamais de connexion coupée sans réponse
                self._error(500, "other", "Erreur interne", repr(e))

        def do_DELETE(self):
            match = JOB_PATH.match(urlparse(self.path).path)
            if match and not match.group(2) and manager.delete(match.group(1)):
                return self._send(200, {"deleted": match.group(1)})
            self._error(404, "not_found", "Tâche introuvable")

    return Handler


def main() -> None:
    settings = from_env()
    settings.data_dir.mkdir(parents=True, exist_ok=True)
    cookies = CookieStore(settings.cookies_file)
    guard = DiskGuard(settings.data_dir, settings.disk_floor)
    manager = JobManager(settings, Downloader(guard), cookies, guard)
    manager.start()
    server = ThreadingHTTPServer(("0.0.0.0", settings.port), make_handler(manager, cookies, guard))
    print(f"ytdl : écoute sur le port {settings.port}", flush=True)
    server.serve_forever()


if __name__ == "__main__":
    main()
```

```python
"""Vraie page et vraie API, faux téléchargeur, sans réseau : python3 -m tests.devserver

Liens de démo : n'importe quelle URL http(s) (vidéo), https://example.com/playlist
(3 vidéos de formats différents : la fusion demande une décision) et
https://example.com/erreur (cookies expirés).
"""
import tempfile
from http.server import ThreadingHTTPServer
from pathlib import Path
from urllib.parse import unquote, urlparse

from tests.fakes import FakeAssembler, FakeDownloader, demo_playlist
from ytdl.config import Settings
from ytdl.cookies import CookieStore
from ytdl.disk import DiskGuard
from ytdl.errors import JobError
from ytdl.jobs import JobManager
from ytdl.server import make_handler


def main() -> None:
    data = Path(tempfile.mkdtemp(prefix="ytdl-dev-"))
    settings = Settings(data_dir=data, disk_floor=0)
    cookies = CookieStore(settings.cookies_file)
    guard = DiskGuard(data, 0)
    downloader = FakeDownloader(
        playlists={"https://example.com/playlist": demo_playlist(3, "Playlist de démo")},
        errors={"https://example.com/erreur": JobError("cookies", details="ERROR: Sign in to confirm you're not a bot")},
        delay=1.0,
    )
    manager = JobManager(settings, downloader, cookies, guard, FakeAssembler(compatible=False))
    manager.start()
    base = make_handler(manager, cookies, guard)
    jobs_dir = settings.jobs_dir.resolve()

    class DevHandler(base):
        def do_GET(self):
            # En prod, Caddy sert /files ; ici, un équivalent minimal.
            path = unquote(urlparse(self.path).path)
            if path.startswith("/files/"):
                target = (jobs_dir / path.removeprefix("/files/")).resolve()
                if target.is_file() and target.is_relative_to(jobs_dir):
                    data = target.read_bytes()
                    self.send_response(200)
                    self.send_header("Content-Length", str(len(data)))
                    self.send_header("Content-Disposition", "attachment")
                    self.end_headers()
                    self.wfile.write(data)
                    return
            super().do_GET()

    print("http://localhost:8000  (données : " + str(data) + ")", flush=True)
    ThreadingHTTPServer(("127.0.0.1", 8000), DevHandler).serve_forever()


if __name__ == "__main__":
    main()
```

```js
// Page unique de ytdl (spec §6) : analyse d'un lien, choix du format, suivi des tâches.
// Les titres viennent de sites tiers : toujours textContent, jamais innerHTML.
const $ = (id) => document.getElementById(id);

  queued: "En attente",

  error: "Erreur",

async function api(method, path, body) {
  const response = await fetch(path, {
    method,
    headers: body ? { "Content-Type": "application/json" } : {},
    body: body ? JSON.stringify(body) : undefined,
  });
  const data = await response.json().catch(() => ({}));
  if (!response.ok) throw data.error || { message: `Erreur ${response.status}` };
  return data;
}

function el(tag, attrs = {}, ...children) {
  const node = document.createElement(tag);
  for (const [key, value] of Object.entries(attrs)) {
    if (key.startsWith("on")) node.addEventListener(key.slice(2), value);
    else node.setAttribute(key, value);
  }
  node.append(...children.filter((child) => child !== null && child !== undefined));
  return node;
}

const known = (value) => value !== null && value !== undefined;
const checked = (name) => document.querySelector(`input[name="${name}"]:checked`).value;
const clock = (t) => new Date(t * 1000).toLocaleTimeString("fr-FR", { hour: "2-digit", minute: "2-digit" });

function bytes(n) {
  if (!known(n)) return "taille inconnue";
  if (n >= GB) return `${(n / GB).toFixed(1).replace(".", ",")} Go`;
  return `${Math.max(1, Math.round(n / 2 ** 20))} Mo`;
}

function duration(seconds) {
  if (!known(seconds)) return "";
  const s = Math.max(0, Math.round(seconds));
  const h = Math.floor(s / 3600);
  const m = Math.floor((s % 3600) / 60);
  if (h) return `${h} h ${String(m).padStart(2, "0")}`;
  return `${m} min ${String(s % 60).padStart(2, "0")}`;
}

function showError(err) {
  $("form-error").textContent = err.message || "Erreur";

function renderJob(job) {
  const progress = job.progress || {};
  const mode = { zip: "ZIP", concat: "un seul fichier" }[job.playlist_mode];
  const li = el("li", { class: `job ${job.state}` },
    el("p", { class: "title" }, job.title || job.url),
    el("p", { class: "muted" }, [STATES[job.state], job.format.toUpperCase() + (job.height ? ` ${job.height}p` : ""), mode]
      .filter(Boolean).join(" · ")),
  );
  if (job.state === "downloading" || job.state === "processing") {
    if (known(progress.percent)) li.append(el("progress", { max: "100", value: String(progress.percent) }));
    const bits = [];
    if (progress.items) bits.push(`vidéo ${progress.item}/${progress.items}`);
    if (known(progress.percent)) bits.push(`${Math.round(progress.percent)} %`);
    if (progress.speed_bps) bits.push(`${bytes(progress.speed_bps)}/s`);
    if (known(progress.eta_s)) bits.push(`${duration(progress.eta_s)} restantes`);
    if (bits.length) li.append(el("p", { class: "muted" }, bits.join(" · ")));
  }
  if (job.skipped.length) li.append(el("p", { class: "muted" }, `${job.skipped.length} indisponible(s) : ${job.skipped.join(", ")}`));
  if (job.note) li.append(el("p", { class: "muted" }, job.note));
  if (job.state === "error") {
    li.append(
      el("p", { class: "error" }, job.error.message),
      el("details", {}, el("summary", {}, "Détails"), el("pre", {}, job.error.details || "—")),
    );
  }
  const actions = el("div", { class: "actions" });
  if (job.state === "ready") {
    actions.append(el("a", { class: "button", href: job.file.url, download: job.file.name }, `Récupérer · ${bytes(job.file.size)}`));
    li.append(el("p", { class: "muted" }, `Effacée à ${clock(job.expires_at)}`));
  }
  if (job.state === "awaiting_decision") {
    li.append(el("p", {}, `Les vidéos n'ont pas toutes le même format : il faut tout ré-encoder (≈ ${duration(job.decision.reencode_estimate_s)} de calcul).`));
    actions.append(
      el("button", { onclick: () => act("POST", `/api/jobs/${job.id}/decision`, { choice: "reencode" }) }, "Ré-encoder"),
      el("button", { onclick: () => act("POST", `/api/jobs/${job.id}/decision`, { choice: "zip" }) }, "ZIP à la place"),
    );
  }
  const running = ["queued", "downloading", "processing"].includes(job.state);
  actions.append(el("button", { class: "secondary", onclick: () => act("DELETE", `/api/jobs/${job.id}`) }, running ? "Annuler" : "Supprimer"));
  li.append(actions);
  return li;
}

async function refresh() {
  try {
    const [jobs, status] = await Promise.all([api("GET", "/api/jobs"), api("GET", "/api/status")]);
    const snapshot = JSON.stringify(jobs);
    if (snapshot !== lastJobs) {
      // Ne redessine que si quelque chose a changé : un volet « Détails » ouvert le reste.
      lastJobs = snapshot;
      $("jobs").replaceChildren(...jobs.map(renderJob));
      $("empty").hidden = jobs.length > 0;
    }
    const banner = $("banner");
    banner.hidden = status.cookies !== "absent" && status.cookies !== "expired";
    banner.textContent = status.cookies === "absent"
      ? "Cookies absents : dépose cookies.txt sur le VPS (voir le README)."
      : "Cookies expirés : à renouveler (voir le README).";
  } catch {
    // Réseau coupé (téléphone en veille…) : on réessaie au prochain tour.
  }
}
```

`deploy/Caddyfile-block` (ajouté en fin de Caddyfile ; indentation par tabulations) :

```

# ---------------------------------------------------------------------------
# ytdl - interface yt-dlp personnelle (github.com/Tsaef/ytdl).
# Mot de passe : YT_USER / YT_HASH dans caddy/auth.env.
# /files/* : fichiers termines servis ici, avec reprise (Range) ; jobs/ est
# monte en lecture seule sur /ytdl-jobs. Le reste part au conteneur.
# ---------------------------------------------------------------------------
yt.{$DOMAIN} {
	import common
	basic_auth {
		{$YT_USER} {$YT_HASH}
	}
	handle_path /files/* {
		root * /ytdl-jobs
		header Content-Disposition attachment
		file_server
	}
	handle {
		reverse_proxy ytdl:8000
	}
}
```

`deploy/remote.sh` :

```sh
#!/bin/sh
# Partie serveur de deploy/install.sh (ne pas lancer à la main). Sauvegarde, modifie,
# valide, et restaure tout en cas d'échec : Caddy ne redémarre qu'avec une
# configuration validée, sinon tous les sites du VPS tomberaient.
set -eu
cd "$HOME/stack"
STAMP=$(date +%Y%m%d-%H%M%S)
FILES="docker-compose.yml caddy/Caddyfile caddy/auth.env"

if grep -q '^  ytdl:' docker-compose.yml; then
  echo "ytdl est déjà dans docker-compose.yml : rien à faire." >&2
  exit 1
fi
for f in $FILES; do cp "$f" "$f.bak-$STAMP"; done
restore() {
  for f in $FILES; do cp "$f.bak-$STAMP" "$f"; done
  echo "ÉCHEC : fichiers restaurés depuis les sauvegardes .bak-$STAMP" >&2
  exit 1
}

mkdir -p apps/ytdl apps/ytdl-data/jobs

python3 - <<'PY' || restore
from pathlib import Path
compose = Path("docker-compose.yml")
text = compose.read_text()
mount = "      - caddy_config:/config\n"
anchor = "\nnetworks:\n"
assert text.count(mount) == 1, "montage caddy_config introuvable"
assert text.count(anchor) == 1, "section networks: introuvable"
text = text.replace(mount, mount + "      - ./apps/ytdl-data/jobs:/ytdl-jobs:ro\n")
text = text.replace(anchor, "\n" + Path("/tmp/compose-service.yml").read_text() + anchor)
compose.write_text(text)
PY

cat /tmp/Caddyfile-block >> caddy/Caddyfile
printf 'YT_USER=%s\nYT_HASH=%s\n' "$YT_USER" "$YT_HASH" >> caddy/auth.env

docker compose config -q || restore
# Validation dans un conteneur jetable avec la configuration du service : le Caddy
# en service n'est pas touché tant que tout n'est pas valide.
docker compose run --rm --no-deps --name "caddy-validate-$STAMP" caddy \
  caddy validate --config /etc/caddy/Caddyfile >/dev/null 2>&1 || restore
docker compose up -d caddy

cp ~/.ssh/authorized_keys ~/.ssh/authorized_keys.bak-$STAMP
echo "command=\"$HOME/stack/deploy-gate.sh $HOME/stack/apps/ytdl ytdl\",restrict $PUBKEY" >> ~/.ssh/authorized_keys

rm -f /tmp/compose-service.yml /tmp/Caddyfile-block /tmp/remote.sh
echo "VPS prêt : Caddy recréé, clé de déploiement ajoutée (sauvegardes .bak-$STAMP)."
```

`deploy/install.sh` :

```sh
#!/bin/sh
# Installation initiale de ytdl sur le VPS (spec §14). À relire, puis à lancer UNE
# fois depuis le Mac :   sh deploy/install.sh
# Prérequis : alias SSH « vps », gh connecté, dépôt Tsaef/ytdl et son environnement
# « production » déjà créés.
set -eu
cd "$(dirname "$0")"

printf "Utilisateur pour yt.tsaef.fr : "
read -r YT_USER
case "$YT_USER" in
  ''|*[!A-Za-z0-9._-]*) echo "Utilisateur invalide (lettres, chiffres, . _ - uniquement)" >&2; exit 1 ;;
esac
stty -echo
printf "Mot de passe : "
read -r YT_PASS
stty echo
echo
[ -n "$YT_PASS" ] || { echo "Mot de passe vide" >&2; exit 1; }

# Le mot de passe passe par l'entrée standard : jamais dans une ligne de commande.
YT_HASH=$(printf '%s\n' "$YT_PASS" | ssh vps 'docker exec -i caddy caddy hash-password')
case "$YT_HASH" in
  '$2'*) ;;
  *) echo "Hachage inattendu : $YT_HASH" >&2; exit 1 ;;
esac

KEYDIR=$(mktemp -d)
trap 'rm -rf "$KEYDIR"' EXIT
ssh-keygen -q -t ed25519 -N "" -C gha-deploy-ytdl -f "$KEYDIR/key"

scp -q compose-service.yml Caddyfile-block remote.sh vps:/tmp/
ssh vps "YT_USER='$YT_USER' YT_HASH='$YT_HASH' PUBKEY='$(cat "$KEYDIR/key.pub")' sh /tmp/remote.sh"

# La clé privée ne vit que dans le secret GitHub ; le dossier temporaire est effacé (trap).
gh secret set SSH_KEY --env production --repo Tsaef/ytdl < "$KEYDIR/key"
echo "Terminé. Dépose maintenant cookies.txt (voir le README), puis pousse sur main."
```

`README.md` :

~~~markdown
# ytdl

Interface web personnelle pour [yt-dlp](https://github.com/yt-dlp/yt-dlp), en ligne sur
`https://yt.tsaef.fr` derrière un mot de passe. On colle un lien, on choisit MP4 ou MP3
(et la qualité), on récupère le fichier ; le serveur l'efface ensuite. Une playlist
donne un ZIP, ou un seul fichier où les vidéos sont mises bout à bout avec un chapitre
par vidéo.

Conception : [docs/superpowers/specs/2026-10-03-ytdl-design.md](docs/superpowers/specs/2026-10-03-ytdl-design.md).

## Cookies YouTube

YouTube refuse yt-dlp sans session connectée (« Sign in to confirm you're not a bot »).
ytdl utilise les cookies d'un **compte secondaire**, jamais ceux du compte principal.
À refaire quand la page affiche « Cookies expirés » :

1. Ouvrir une **fenêtre de navigation privée**, se connecter à YouTube avec le compte secondaire.
2. Dans le même onglet, aller sur `https://www.youtube.com/robots.txt`.
3. Exporter les cookies de `youtube.com` au format `cookies.txt` (Netscape) avec une
   extension d'export autorisée en navigation privée (par ex. « Get cookies.txt LOCALLY »).
4. **Fermer la fenêtre privée** sans se déconnecter : le navigateur n'utilise plus cette
   session, YouTube ne la fait donc pas tourner.
5. Déposer le fichier sur le VPS :

   ```bash
   scp cookies.txt vps:stack/apps/ytdl-data/cookies.txt
   ssh vps chmod 600 stack/apps/ytdl-data/cookies.txt
   ```

Pas de redémarrage : le fichier est relu à chaque tâche.

## Réglages

Variables d'environnement du conteneur (service `ytdl` de `~/stack/docker-compose.yml`) :

| Variable | Défaut | Rôle |
|---|---|---|
| `YTDL_WORKERS` | `2` | téléchargements en parallèle |
| `YTDL_DISK_FLOOR` | `10` | Go toujours laissés libres sur le VPS |
| `YTDL_TTL` | `6` | heures avant l'effacement d'une tâche terminée |
| `YTDL_REENCODE_FACTOR` | `1.0` | secondes de calcul par seconde de vidéo en 1080p (estimation affichée avant un ré-encodage) |
| `YTDL_DATA` | `/data` | `cookies.txt`, `jobs/`, `cookie-copies/` |

## Développement

```bash
python3 -m unittest discover -s tests -t .   # Mac : tests ffmpeg sautés
docker build -t ytdl:dev . && docker run --rm -v "$PWD:/src" -w /src -e YTDL_REQUIRE_FFMPEG=1 ytdl:dev python -m unittest discover -s tests -t .
python3 -m tests.devserver                   # vraie page, faux téléchargeur : http://localhost:8000
```

## Déploiement

- Push sur `main` → tests + build de l'image → **validation** (environnement
  `production`) → `rsync` vers `~/stack/apps/ytdl` puis reconstruction du service.
- Installation initiale, une seule fois : `sh deploy/install.sh` (mot de passe du site,
  clé de déploiement bridée, service compose, bloc Caddy ; sauvegardes `.bak-*`).
- **Quand YouTube casse yt-dlp** : Dependabot ouvre chaque semaine une PR qui monte
  yt-dlp ; la fusionner puis valider le déploiement. Pour forcer : modifier la version
  dans `requirements.txt` et pousser.

## Test manuel après un déploiement

1. `https://yt.tsaef.fr` demande un mot de passe.
2. Une vidéo courte en MP4 720p : progression, puis « Récupérer » donne un MP4 lisible
   sur le téléphone.
3. La même en MP3 : fichier lisible, 192 kb/s.
4. Une petite playlist (3 ou 4 vidéos) en ZIP : fichiers numérotés « 01 - … ».
5. La même en « un seul fichier » : chapitres visibles dans VLC ; si les vidéos
   diffèrent, la page propose « Ré-encoder » ou « ZIP à la place ».
6. « Supprimer » efface la tâche ; une tâche prête disparaît au bout de 6 h.

## Limites connues

- Un redémarrage du conteneur (donc un déploiement) interrompt les tâches en cours et
  efface leurs fichiers.
- Les directs ne sont pas pris en charge ; le ré-encodage d'une playlist est plafonné à 1080p.
- Si le manque de place empêche de créer un fichier unique, la playlist est livrée en ZIP.
~~~
